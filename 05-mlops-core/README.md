# 05 - MLOps Lifecycle

Engineering reproducible, scalable, automated, and observable machine learning systems.

### Modules
1. **01-data-versioning/**: Tracking large datasets and model files with DVC.
2. **02-experiment-tracking/**: Logging runs, parameters, metrics, and models with MLflow & W&B.
3. **03-containerization/**: Building lean Docker containers for ML inference and training.
4. **04-model-serving/**: High-performance inference APIs using FastAPI, Triton, and vLLM.
5. **05-orchestration/**: Managing data and model pipelines with Airflow or Prefect.
6. **06-cicd-automation/**: Automating testing, building, and deployment with GitHub Actions & CML.
7. **07-monitoring-observability/**: Detecting data and concept drift with Evidently AI; Prometheus & Grafana monitoring.
