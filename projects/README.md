# 🛠️ Projects Portfolio

This directory holds end-to-end practical projects demonstrating applied AI and production MLOps engineering.

---

## 🏗️ Project Architecture Checklist
Every project in this directory should strive to include:
1. **Clear Problem Statement & Business Objective**
2. **Dataset Documentation & DVC Tracking**
3. **Exploratory Data Analysis & Feature Engineering**
4. **Reproducible Training Pipeline & Experiment Tracking (MLflow)**
5. **Model Packaging & Validation**
6. **Containerized API Service (FastAPI + Docker)**
7. **CI/CD Pipeline (GitHub Actions)**
8. **Deployment & Drift Monitoring (Evidently / Prometheus)**
